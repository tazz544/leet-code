# LeetCode

Solutions to LeetCode problems, written mostly in TypeScript.

Submissions are pushed automatically by [leetcode-sync](https://github.com/joshcai/leetcode-sync)
on a daily schedule, so the commit history reflects when problems
were actually solved.

## Structure

solutions/
  0001-two-sum/
    README.md    problem statement
    solution.ts  accepted submission

## Notes

Only accepted submissions are included. Where a solution is not optimal,
I usually leave a comment on the complexity and what a better approach
would look like.
